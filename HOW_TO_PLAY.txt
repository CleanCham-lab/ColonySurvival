========================================
 Colony Survival — Lab Xmas Edition  v2.0.0
========================================

12월 24일 밤, 모두 퇴근한 배양실.
아침 9시(실제 15분)까지 컨탐으로부터 콜로니를 지키고,
마지막에 나타나는 최종 심사위원 Reviewer #2를 쓰러뜨려라!

[실행]  Godot 같은 프로그램을 따로 설치할 필요가 없습니다.
  • Windows : ColonySurvival.exe 더블클릭
              파란 "Windows의 PC 보호" 창이 뜨면 → 추가 정보 → 실행
  • Mac     : zip을 풀고 Colony Survival.app 더블클릭
              (응용 프로그램 폴더로 옮겨 두면 편합니다)
              "확인되지 않은 개발자" / "확인할 수 없음" 경고가 뜨면 →
              시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"

[조작]
  이동            WASD / 방향키 / 게임패드 왼쪽 스틱
  공격            자동!
  레벨업 선택     1·2·3 키, ↑↓ + Enter, 또는 마우스 클릭
  다시 뽑기       R
  일시정지        Esc
  전체화면        Windows: F11   /   Mac: ⌘ + Ctrl + F
                  (설정 메뉴에도 있음)

[메뉴]
  시작하기  → 실험 설정(모드·스테이지·난이도) → 셀라인 고르기
    모드      정규 실험 / 야근 모드(끝없이 버티기) / 오늘의 실험 조건(날짜마다 버프+디버프)
    스테이지  배양접시 / 클린벤치(층류가 아래로 밀고, UV 램프가 주기적으로 쓸고 지나감)
    난이도    학부연구생(쉬움) / 대학원생(보통) / 리뷰어 모드(어려움, 연구비 ×1.5)
  연구실    런에서 번 연구비로 영구 강화 구매 (HP·피해·쿨다운·부활·셀라인 해금 등)
  설정      전체/음악/효과음 볼륨, 색각 친화 모드, 화면 흔들림, 피해 숫자, FPS, 전체화면

[색의 의미]  형광현미경처럼 보입니다
  파랑·시안 = 나와 내 무기    초록 = 주울 것(ATP·선물상자)
  빨강     = 적·적 공격       노랑 = 곧 공격이 온다는 경고
  (설정 → 색 구분 모드 "색각 친화": 파랑 = 나, 노랑 = 주울 것, 주황 = 적, 흰색 = 경고)

[저장]  연구비·해금·기록·설정은 자동 저장됩니다.
