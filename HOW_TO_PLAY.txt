12월 24일 밤, 모두 퇴근한 연구소 — 세포들의 야근이 시작된다.
배양접시에서 분석 서버실까지 다섯 구역을 지나,
최종 심사위원 Reviewer #2에게서 Accept를 받아 내라!

[실행]  따로 설치할 프로그램은 없습니다.
  • Windows : ColonySurvival.exe 더블클릭
              파란 "Windows의 PC 보호" 창이 뜨면 → 추가 정보 → 실행
  • Mac     : Colony Survival.app 더블클릭 (응용 프로그램 폴더로 옮겨 두면 편합니다)
              "확인되지 않은 개발자" / "열 수 없습니다" 경고가 뜨면 → 완료를 누르고
              시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"
              (처음 한 번만 하면 됩니다. macOS 12 이상)

[조작]
  이동            WASD / 방향키 / 게임패드 왼쪽 스틱
  공격            자동!
  대시            Space 또는 왼쪽 Shift  (튀어 나가는 동안 무적)
  궁극기          Q 또는 E  (화면 아래 게이지가 다 차면)
  레벨업 선택     1·2·3 키, ←→ + Enter, 또는 마우스 클릭
  다시 뽑기       R
  일시정지        Esc 또는 P
  전체화면        Windows: F11   /   Mac: ⌘ + Ctrl + F   (설정 메뉴에도 있음)

[진행]
  실험 시작 → 구역 · 셀라인 · 난이도를 고릅니다.
  구역 시간이 끝나면 보스가 나오고, 쓰러뜨리면 다음 구역이 열립니다.
    1 배양접시 → 2 클린벤치 → 3 PCR실 → 4 시퀀싱실(숏리드/롱리드) → 5 분석 서버실
  런에서 번 연구비로 연구실에서 영구 강화를 삽니다.
  어렵다면 난이도를 "쉬움 · 학부연구생"으로 — 받는 피해가 줄고 체력이 천천히 회복됩니다.

[알아 두면 좋은 것]
  • 초록 결정(ATP)을 주우면 경험치. 레벨업마다 3개 중 하나를 고릅니다.
  • 팁 박스를 부수면 핫코코아(HP 회복)가 나옵니다.
  • 일부 무기는 적의 탄환을 확률로 지웁니다 (Nanopore Ring 75% 등 — 도감 참고).
  • 노란 고리를 두른 적은 엘리트, 바닥의 색칠된 원·선은 곧 공격이 떨어질 자리입니다.

[언어]  설정 → 언어 Language 에서 한국어 / English

[저장]  연구비·해금·도감·설정은 자동 저장됩니다.
